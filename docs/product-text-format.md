# Единые правила оформления описаний продуктов

Эти правила обязательны для ручного редактирования, вставки из документов и заполнения через ChatGPT. Используй текущие данные и изменяй только запрошенный продукт и поле. Не заменяй общий план, задачи или соседние поля. Не выдумывай отсутствующие сведения.

## Структура

Два независимых поля продукта: description («Описание») и result («Результат»). Внутри «Описания» допустимы несколько инициатив. Заголовок каждой инициативы — h3. Разделы «Фичи», «Проблема», «Решение» — h4. Основной текст — p. Фичи — ul/li, последовательные шаги — ol/li; списки можно вкладывать. Предпосылки, уверенность, источник и трудоёмкость — p с data-text-style="note". Результат — ожидаемый результат, если известен; иначе поле остаётся пустым. Символы ☑️ — обычные эмодзи, не интерактивные чекбоксы.

## Оформление

Размеры и шрифт определяет интерфейс: заголовок инициативы 16 px, подзаголовок и основной текст 14 px, примечание 12 px. Не передавай font-family, font-size, произвольные классы и стили. Явный обычный абзац: p data-text-style="body". Допускаются b/strong, i/em, s/del, br, ссылки a href="https://..." (также http и mailto).

Цвет текста при необходимости: основной #2c3828, серый #78816f, красный #b54737, охра #986515, зелёный #397451, синий #4f749b, фиолетовый #80609a. Фон выделения: жёлтый #fff0b3, зелёный #dcefd8, голубой #dceafa, розовый #f5dfe8. Применяй через span style="color:...;background-color:...". По умолчанию текст основной, без цветного фона. Не раскрашивай весь документ.

Редактор приводит вставку и отображение к этому набору: сторонние размеры, шрифты и неподдерживаемое оформление удаляются; цвета приводятся к палитре. Ограничение поля — 24 КБ сериализованного HTML. После записи прочитай результат и проверь текст, структуру и ссылки. Очистка оформления сбрасывает выделенный текст к обычному, сохраняя содержание.

## Пример

<h3>Название инициативы ☑️</h3>
<h4>Фичи</h4>
<ul><li>Описание функции.</li></ul>
<h4>Проблема</h4>
<p>В чём проблема.</p>
<h4>Решение</h4>
<p>Как её решаем.</p>
<p data-text-style="note"><b>Трудоёмкость:</b> normal.<br><b>Источник:</b> <a href="https://example.com">Название источника</a>.</p>
